# 大连奶龙大学 · 整活特别版

参考用户提供的「大连奶龙大学」制作的校园趣味网站。原目录中的镜像保持原样；此目录为独立新站源码。

静态 HTML、CSS 和原生 JavaScript，无需安装依赖。

```bash
python3 -m http.server 8081 --bind 127.0.0.1 --directory dist
```

功能：六个虚构学院及详情、新闻分类和全文、随机课表、食堂抽签、昵称与学院生成 PNG 入学纪念卡、响应式导航。

所有用户输入仅在浏览器内处理，无后端与个人信息上传。

视觉素材参考来源：http://大连奶龙大学.com/ 。校徽和 AI 主题图沿用参考站素材；校园摄影原始来源为大连东软信息学院。相关权利归原权利人所有。
