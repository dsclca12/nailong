# 大连奶龙大学 · 整活特别版

一个校园主题的趣味静态网站。内容为虚构创作，不提供真实招生、学历或学位服务。

## 本地预览

需要 Python 3。进入仓库目录后运行：

```bash
python3 -m http.server 8081 --bind 127.0.0.1 --directory dist
```

打开 <http://127.0.0.1:8081> 即可预览。项目使用原生 HTML、CSS 和 JavaScript，不需要安装依赖或构建。

## 功能

- 浏览虚构学院介绍与校园新闻
- 随机生成趣味课表和食堂选择
- 生成入学纪念卡
- 适配桌面和移动屏幕

用户输入仅在浏览器本地用于生成纪念卡，不会发送到服务器。

## 目录

```text
dist/                 网站文件，可直接部署为静态站点
  assets/             图片和校徽
  app.js              页面交互
  index.html          页面内容
  styles.css          页面样式
.openai/hosting.json  Codex Sites 部署配置
```
